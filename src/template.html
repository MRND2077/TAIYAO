客户跟进看板

把一批客户的跟进记录，变成一张能点、能筛、能下钻到原文的看板。
这份文件本身是空的 —— 数据来自你，或者来自自带的一份演示数据。

看板里会出现哪些字段？我需要准备什么？

你只需要准备一张客户表。除名称外每个字段都可以缺，缺了会显示为「未记录」而不是空白：

字段含义示例
name客户名称（必填）客户 01
account渠道账号 / 昵称acme_pm
role联系人角色决策人 / 采购
profile客户画像50 人团队 · 已试用
level健康度分级（必填）g / l / y / r
a1 a2 a3三个关键动作，1=已完成 0=明确未完成 -1=未记录1 / 0 / -1
lastContact最近互动间隔（天），-1 表示未记录3
note备注沿用上轮
updatedAt该条数据的截止日期10-15

另可提供 docs（以客户 id 为 key 的原文档案与分析报告），用于点击卡片时下钻查看。
